# Cybercraft Implants
[Download](https://github.com/vata-ot-nata/cybercraft-implants/releases/latest)

Cybercraft Implants is a plugin from the CyberCraft paper-plugin series. It adds various cyberpunk implants.  
Implants can only be removed by dying or by using the `/clear` command.  

There are four implants in total:
- Sandevistan: When activated, it leaves a rainbow-colored trail. It slows down all players within a radius of several dozen blocks and grants the user speed and jump boost. Using it for too long results in negative effects.
- Sandevistan (Gradient): Identical to the standard Sandevistan, but leaves a blue-violet trail instead of a rainbow one.
- Leg Implant: Grants jump boost and speed when activated.
- Leg Implant (Gradient): Identical to the standard version.

## Installation

1. [Download the latest implants.jar](https://github.com/vata-ot-nata/cybercraft-implants/releases/latest) and place it in your `plugins` folder
2. Restart the server
3. Use commands below to get implants.

## Commands

| Implant | Give command |
|---------|-----------|
| `Sandevistian` | `/give @s minecraft:iron_chestplate[custom_name='{"text":"Sandevistian"}'] 1` |
| `Sandevistian (Gradient)` | `/give @s minecraft:iron_chestplate[custom_name='{"text":"Sandevistian (Gradient)"}'] 1` |
| `Leg Implant` | `/give @s minecraft:iron_leggings[custom_name='{"text":"Leg Implant"}'] 1` |
| `Leg Implant (Gradient)` | `/give @s minecraft:iron_leggings[custom_name='{"text":"Leg Implant (Gradient)"}'] 1` |
